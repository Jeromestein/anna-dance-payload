## Naming Convention

- Use lowercase descriptive English names in kebab-case.
- Keep dates in `YYYY-MM-DD` format.
- Retain original photo numbers when they are useful for tracing source files.
- Add orientation or edition markers only when they distinguish otherwise similar assets, such as `vertical` or `final`.
